# SEO Indexing Weekly Reports

Drop weekly source exports here using dated subfolders.

Example:
- `reports/seo-indexing/2026-02-25/`
  - `gsc-pages.csv`
  - `gsc-sitemaps.csv`
  - `bing-index-coverage.csv`
  - `crawl-summary.csv`
  - `notes.md`

Naming is flexible, but keep one folder per reporting week (`YYYY-MM-DD`).
