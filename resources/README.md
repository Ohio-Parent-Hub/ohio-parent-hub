# Resources

This folder stores external reference materials used for content, SEO, and compliance decisions.

## Structure

- `sutq/` — Ohio SUTQ standards, QRIS references, provider-quality docs
- `seo/` — SEO policy notes, search quality references, crawl/indexing guidance
- `policies/` — legal/compliance/trust policy references

## Suggested naming

Use dates and clear source names so references are easy to track.

Examples:

- `sutq/2026-02-26-ohio-appendix-a-rule-2-17-01.pdf`
- `seo/2026-02-26-google-helpful-content-notes.md`
- `policies/2026-02-26-ohio-childcare-licensing-summary.md`

## Working guideline

When adding or updating content tied to external standards, place the source here first so implementation can reference a stable local file.
